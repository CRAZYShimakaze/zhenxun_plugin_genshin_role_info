# genshin_role_info

真寻机器人的原神角色面板插件

展示橱窗中角色的面板和伤害数据(与原神角色卡插件部分命令有冲突，建议只安装一个)

## 使用

- 原神绑定 UID（或绑定原神 UID；手动绑定 UID 须为 9 位且首位为 1-9）
- 原神解绑
- 米游社更新原神面板（需先扫码登录米游社账号，且账号仅有一个原神 UID）
- 角色面板（例:甘雨面板、甘雨面板@用户、甘雨面板104442596）
- 更新/刷新原神面板（末尾可直接写 UID；省略时使用当前发送者已绑定的 UID）
- 原神角色排行
- XX(花羽沙杯冠)适配
- XX(花羽沙杯冠)推荐
- XX(乐团/魔女/...)套推荐
- XX(乐团/魔女/...)独立套推荐
- XX(花羽沙杯冠/套)推荐N（N 为伤害表项目序号，例如:胡桃魔女套推荐2、胡桃火伤杯推荐2）
- XX评分排行/榜单（仅群聊，例:胡桃评分排行；评分排行不可带序号）
- XX伤害排行/榜单N（仅群聊，例:胡桃伤害排行5；N 为从 1 开始的伤害项目序号）
- 最强XX/群最强XX（例:最强甘雨；群内仅按圣遗物评分判断）
- 最菜XX/群最菜XX
- 圣遗物榜单（别名:圣遗物排行）
- 群圣遗物榜单（别名:群圣遗物排行）
- 圣遗物导入（先发送命令查看步骤，再私聊发送 good.json）
- 重置最强XX（仅超级用户可用，群聊）
- 检查原神面板更新 (仅超级用户可用)

## 评分与排行

- 更新原神面板或米游社同步后，会按当前角色圣遗物逐件计算 Miao-Plugin 评分并汇总为角色评分，同时重建本地圣遗物榜单；ACE* 计入大毕业圣遗物，ACE 计入小毕业圣遗物，毕业统计按圣遗物件数计算。
- 评分排行和伤害排行均只在群聊处理，最多展示 16 名成员。命令实时读取群成员列表和群名片，再通过本地 QQ-UID 绑定读取对应 UID 的角色缓存；评分排行使用缓存中的角色评分，伤害排行在命令时对缓存角色数据调用 Miao-Plugin 伤害计算。
- 排行计算不重新请求 Enka 或米游社，也不读取已保存的群圣遗物榜单；没有绑定、角色缓存或已写入评分的成员会被跳过。伤害排行的 N 必须对应伤害表中去掉“额外说明”后的 1-based 项目序号。
- 最强/最菜使用群内持久化的角色面板图，并且只按圣遗物评分比较；带 UID 或 @ 查询的角色不会写入群内最强/最菜记录。

## 伤害计算

- 有可用规则时，角色面板会调用插件内置的 Miao-Plugin 兼容计算引擎，按角色、天赋、武器、圣遗物套装、元素反应及 Buff 规则计算伤害。
- 伤害表左侧展示暴击伤害、右侧展示期望伤害；Buff 列表展示默认伤害项目对应的计算说明。
- 推荐命令不带数字时按圣遗物评分排序；末尾添加正整数时，数字对应面板伤害表中去掉“额外说明”后的项目序号，并按该项目的期望伤害排序。
- 带序号的套装推荐会从缓存圣遗物中按目标项目的期望伤害选择整套搭配；带序号的单部位推荐会展示该部位按期望伤害排序的圣遗物，并以伤害值代替原评级位置。无序号时两类推荐均按评分。
- 伤害推荐需要遍历缓存中的圣遗物，计算期间机器人会先发送匹配提示；推荐结果仅基于当前圣遗物缓存

## 数据与同步

- 普通角色查询优先读取插件的 UID 本地缓存；首次查询或显式更新时通过 MicroGG/Enka 获取橱窗数据。更新会重建角色、圣遗物归属、角色评分和榜单缓存。
- 米游社更新使用已登录的米游社账号获取角色详情，自动绑定该账号唯一的原神 UID，并写入同一 UID 本地缓存；同步后会重建圣遗物榜单与毕业统计并生成更新图。账号未登录、没有原神角色或存在多个原神 UID 时不会同步。
